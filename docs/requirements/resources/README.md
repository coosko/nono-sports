# Recursos para requisitos

Aquí se almacenan documentos desestructurados, notas, referencias y cualquier información adicional que ayude a definir los requisitos del proyecto.

Esta carpeta puede contener:

- documentos en bruto y notas de reuniones
- listas de deseos y aportes de stakeholders
- ejemplos de flujos de usuario
- referencias a sistemas existentes o similares
- resultados de investigaciones previas

Cuando se consoliden, estos recursos deben transformarse en requisitos formales dentro de `docs/requirements/requirements.md`.
